# Yuzuno character

`yuzu-character.png` and `yuzu-character-outline.png` are copied unchanged from
an earlier project's `web/src/assets/`, reusing the existing character at the
owner's request. The main image is used for the workspace brand, empty
states, Catch-up, and the small Working indicator; the outline image is used for
the quiet sidebar note.

The owner has confirmed that the images were generated with Codex, and on
2026-10-20 put them under the project's Apache License 2.0. The font in
`fonts/` keeps its SIL Open Font License 1.1 (`fonts/LICENSE-NotoSansSC.txt`).
